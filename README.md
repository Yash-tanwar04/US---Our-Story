# 📖 Yash & Tannu — Our Story, Our Sanctuary ♡

An interactive, romantic, vintage burned-edge digital flipbook diary dedicated to Tannu. Built with React 19, TypeScript, Tailwind CSS, Lucide icons, Framer Motion, and HTML5 Canvas Confetti.

---

## ✨ Features

- **📖 44-Page Realistic Flipbook**: Realistic page-turn physics powered by `react-pageflip` and custom sound effects.
- **🔥 Vintage Burned-Edge Aesthetic**: Real parchment aesthetics with burned borders, coffee rings, washi tapes, and vintage stamps.
- **✨ Full-Screen Pop Reactions**: Tapping forehead kisses, love meters, scratch cards, and coupons explodes into full-screen animations with glowing vignette effects.
- **🎬 Autoplay Filmstrip & 12 Unfiltered Videos**: Dedicated video modal for the "US Unfiltered" candid moments.
- **🎵 Atmospheric Chapter Soundtracks**:
  1. *Stephen Sanchez - Until I Found You*
  2. *New West - Those Eyes*
  3. *KoshalWorld - High On You*
- **📱 Mobile-First Perfection**: Single-page portrait view for phone screens, touch-friendly page turners, and responsive polaroids.
- **💌 Interactive Surprises**: Tap-to-flip polaroids with secret notes, scratch cards, redeemable coupons, voice note simulator, and interactive birthday candle blowing.

## 🚀 Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Lint code
npm run lint

# Build for production
npm run build
```

## 🌐 Deploying to Vercel

1. Push this repository to GitHub:
   ```bash
   git add .
   git commit -m "feat: complete interactive diary for Tannu"
   git remote add origin https://github.com/<your-username>/<your-repo-name>.git
   git push -u origin main
   ```
2. Open [Vercel](https://vercel.com) and click **"Add New Project"**.
3. Import your GitHub repository.
4. Framework Preset: **Vite** (auto-detected).
5. Build Command: `npm run build` (auto-detected).
6. Output Directory: `dist` (auto-detected).
7. Click **Deploy**! 🚀
